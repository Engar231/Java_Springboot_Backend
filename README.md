# 🦖 Jurassic Park Management System (Java & Spring Boot)

A full-stack web application for managing a dinosaur park, built with **Java Spring Boot**, **Maven**, and a dynamic frontend. 

The application implements secure authentication with user/role management, allowing different access permissions for **Admin** and **Guest** accounts, along with password validation logic.

## ✨ Features

- **🔐 Authentication & Password Validation:** Secure registration and login flow with password strength/sequence checks.
- **👥 Role-Based Access Control (RBAC):**
  - **Admin:** Full access to manage park resources, staff, and dinosaurs.
  - **Guest:** Read-only access to view park information and active dinosaurs.
- **🦖 Dinosaur & Staff Management:** Complete CRUD operations to register, view, and organize park assets.
- **🌐 Dynamic Frontend:** Interactive UI for seamless navigation across home, registration, management, and dinosaur catalogs.

---

## 🛠️ Tech Stack

- **Backend:** Java, Spring Boot, Spring Security, Maven
- **Database:** MySQL / H2 Database
- **Frontend:** HTML5, CSS3, JavaScript / Thymeleaf (or Bootstrap)
- **Build Tool:** Maven
